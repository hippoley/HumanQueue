Codex PermissionRequest

Session + turn + tool boundary enter the Gateway. Your decision returns as native allow/deny to the same waiting Codex tool call.
humanq connect codex PermissionRequest → human://approve → allow | deny
real · conservative gate

Cursor high-risk shell

Conversation is observed continuously, while only explicit high-risk beforeShellExecution commands are routed for human approval.
humanq connect cursor beforeShellExecution → permission: allow | deny | ask
real · semantic input

MCP human_ask

Clarification, choice, review or edit blocks inside the same MCP tool call and returns the human result to that exact invocation.
humanq mcp serve human_ask({ uri: "human://clarify" })
real · channel projection

Signed Webhook Channel

A bounded dialogue capsule can appear in another UI. The signed action comes back to the Gateway; the channel never owns a second queue.
humanq channel add webhook ops \ https://channel.example/human X-Human-Channel-Signature: sha256=…
real · outbound-only channel

Telegram long-poll

human:// pushes bounded approval cards to your Telegram chat. A local worker receives callback_query events and resolves localhost — no public inbound Gateway port required.
humanq channel add telegram phone \ --bot-token "$BOT_TOKEN" \ --chat-id "$CHAT_ID" humanq channel run phone

01 · install

Your machine becomes the Human Gateway

No hosted account required. State and audit history can remain on your hardware.
curl -fsSL https://raw.githubusercontent.com/hippoley/human:///main/scripts/install.sh | bash humanq gateway run
02 · onboard

One private gateway token

First run creates ~/.human-queue/config.json and human-queue.db, then gives you an hq_… token.
humanq onboard humanq dashboard humanq doctor humanq gateway status
03 · connect

Point any machine at your queue

Codex, Claude, CI, MCP, n8n or your own app only need HTTP + Bearer token.
curl http://127.0.0.1:7482/v1/human \ -H "Authorization: Bearer hq_xxx" \ -H "Content-Type: application/json" \ -d '{ "uri":"human://approve", "source":"my-agent", "ref":"run-42", "title":"Continue?" }'
